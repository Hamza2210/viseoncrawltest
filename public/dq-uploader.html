Amazon Redshift Beta

Point us at a Redshift table. Via the Data API and a cross-account IAM role, the assessment runs as SQL inside Redshift — only aggregate results (and up to 50 sample failing rows per check) come back. Your data is never copied out, and full tables are profiled (no 100k sampling cap).

Assessment

Amazon S3 file Beta

Point us at a single object (Parquet, CSV, JSON/NDJSON or QVD). A same-account bucket needs only the URI; a cross-account bucket needs a role ARN or read-only access keys.

Assessment

Snowflake Beta

Read a Snowflake table with a read-only role. Checks push down as SQL so only results return.

Assessment

Databricks Beta

Read a Unity Catalog / SQL-warehouse table via a personal access token.

Assessment

PostgreSQL Preview

Read a Postgres table with a read-only user. The endpoint must be reachable from our worker.
